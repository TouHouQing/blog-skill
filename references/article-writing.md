# 文章写作

先确定一个具体读者、一个核心问题和文章能兑现的收获。判断是否需要补材料，再选结构。不要先生成通用的大纲标题，再给每个标题填一段泛论。

| 目的 | 可采用的展开 |
| --- | --- |
| 新闻解读 | 新变化、与以前的差别、证据、影响、适用人群与待确认项 |
| 操作教程 | 目标、前提、关键步骤、可见结果、影响完成的限制与排错 |
| 工具比较 | 具体任务、匹配的比较条件、取舍、成本与适用人群 |
| 原理解释 | 现象或疑问、必要基础、机制、验证、边界、回答开头 |
| 实践复盘 | 目标、实际选择、障碍、结果、理解发生的变化 |

这些是思考路径，按材料合并、调整，不强制写成同样数量的小标题。学习教程、任务指南、参考资料和解释的区别可参考 [Diátaxis](https://diataxis.fr/application/)。

开头尽快给具体信息，允许结果、问题或判断先出现；判断附近跟上证据。背景在需要时解释。开头承诺教操作，后文就应让人完成；开头提出比较，后文就应给判断依据。标题的吸引力来自具体收获、真实差别或问题，不靠夸大影响。

每段承担清楚的任务：提出信息、解释原因、给证据、比较、改变判断或说明边界。段落之间保留因果和指代。写完前半段后，单独读从第一次弱衔接到结尾的整段，检查有无突然换题、重复解释和收尾拖延。

代码前说清要观察什么，代码后解释关键结果；输入、版本和环境影响结论时写明。实测输出必须来自真实执行，未执行的示例注明其用途和预期，不编一段看起来可信的输出。图也需要正文解释，看得见不等于读者知道该看哪里。

结尾解决核心问题，给出可行动的选择或最后一个有依据的判断。没有必要每篇加入宏大升华、未来展望和关注口号。增长目标可体现在可收藏的步骤、可转述的判断、可下载的示例，行动引导随任务需要使用。

通读整篇，而非仅逐句修饰。全文审核覆盖标题承诺、信息增量、论证、来源、图文关系、段落衔接、结尾和语言。保留实用细节，篇幅跟随材料，不为凑长而扩写，也不因反复改稿压缩成提纲。
